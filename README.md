# 弹幕闯关大乱斗

抖音直播弹幕互动闯关游戏：观众发弹幕自动上车，角色自动奔跑，但障碍要靠弹幕才跳得过去——不发「跳」就会撞上掉分。发「冲 / 护」还能加速、开盾，点赞触发全场加速，礼物加分开护盾。OBS 加一个浏览器源就能上直播画面，不需要额外装弹幕工具。

## 快速开始

需要 Node.js 22 以上（本机 24 可以直接用）。

```bash
npm install
npm start
```

1. 打开控制台：<http://127.0.0.1:3000/host>
2. 填直播间号（`https://live.douyin.com/123456789` 里的 `123456789`），点「连接」
3. 右上角变成「弹幕已连接」即可开播

## OBS / 直播伴侣

- 添加「浏览器源」
- 地址：`http://127.0.0.1:3000/overlay`
- 竖屏直播：宽 1080，高 1920（画面按 1080×1920 设计，铺满竖屏画布）；横屏画布填 1920×1080 也能用，会上下留黑边
- 勾选「控制音频通过 OBS」；来源不可见时建议勾「关闭源」，避免语音串到别的场景

开播前先在控制台点「打开直播画面」预览，确认角色、排行榜、弹幕流都在动。

## 玩法

| 弹幕 | 效果 |
| --- | --- |
| 任意弹幕 | 自动上车，生成角色 |
| 加入 / 上车 | 已上车时补 8 分 |
| 跳 / 蹦 | 攒一次跳跃蓄力（最多 3 次），靠近障碍自动起跳；一次只够过一个障碍 |
| 冲 / 加速 / 起飞 | 2.2 秒加速，期间免伤 |
| 护 / 盾 / 保护 | 6 秒护盾 |
| 666 / 加油 | 加分并叠连击 |

- 点赞：累计到 130 触发 8 秒全场加速
- 礼物：角色加 300 分并开 8 秒护盾，全屏彩带
- 每轮 75 秒，前三名结算上榜，6 秒后自动开下一轮
- 画面底部有「本局排行」和「今日总榜」，总榜跨轮累计、重启不丢；换直播间或跨天自动清零
- 角色不会自己躲障碍：没人发「跳」就会撞上，头顶会冒「发『跳』」提示
- 任意观众发「跳」时，3 个 AI 陪跑也会跟着跳，画面不会冷场；AI 不进本局排行，只做陪跑

## 语音播报

开播时不方便说话也能有声音，系统会用 Windows 自带中文语音播报两件事：

- 新观众进直播间：「欢迎 XX 进入直播间，发弹幕就能上车」
- 新观众第一次发弹幕上车：「欢迎 XX 加入闯关」
- 每轮结算：「第 N 轮结束，恭喜 A、B、C 中榜！」
- 没人发弹幕时约每 30 秒解说一句（玩法提示 / 当前领先），有人聊天时自动让位

语音由服务端用本机 SAPI 合成 WAV（`public/tts/`），再通过直播画面里的音频播放，OBS 浏览器源会一起收进直播。控制台可随时用「语音播报：开/关」切掉。

- 默认嗓音 `Microsoft Huihui Desktop`（中文女声，Win10/11 自带）
- 语音播报失败会在服务端控制台打印原因，不影响画面和游戏
- 进房/上车播报最多约每 2.5 秒一条，高峰期限流，避免刷屏
- 用普通 Chrome 预览时浏览器可能拦截自动播放，点一下画面即可解锁；OBS 浏览器源通常直接可播
- 如果 OBS 里没声音：右键浏览器源 → 属性，确认「控制音频通过 OBS」已勾选，并在混音器里检查该源没静音

## 配置

`config.json` 会自动生成/更新：

```json
{
  "port": 3000,
  "roomId": "",
  "roundSeconds": 75,
  "voice": true
}
```

- `roomId` 留空则只跑画面不连弹幕；控制台点「连接」会自动写入
- `roundSeconds` 改轮时长，改完重启服务
- `voice` 语音播报总开关，控制台按钮会同步改这里；也可以加 `voiceName`（SAPI 嗓音名）和 `voiceRate`（-10 到 10，默认 0）
- 今日总榜存在 `data/scores.json`，不用手动维护；删掉文件即清空
- 临时预览结算：打开 `http://127.0.0.1:3000/overlay?round=15`，15 秒一轮

## 本地彩排

控制台「本地彩排」可以模拟观众弹幕（只在本地画面显示，不会发到抖音，模拟观众也不计入今日总榜），用来确认上车、跳跃、礼物横幅和结算是否正常。

## 实现说明与限制

- 弹幕通过抖音网页直播协议只读接入，不需要登录、不发言、不刷数据，只用于自己的直播间
- 该协议不是公开接口，平台更新后可能失效；长期商用请走抖音开放平台「直播小玩法」
- 直播间必须正在直播；下播后自动重连会在下一场开播时接上（内部房间号会换）
- 本机需要能访问 `live.douyin.com`
- 打包的弹幕库为 GPL-3.0，本项目整体按 GPL-3.0-or-later 使用

## 常见问题

**一直显示未连接**

- 确认直播间正在直播，房间号是 `live.douyin.com/` 后面那串数字
- 控制台会显示具体错误（未开播、网络失败、签名失败）
- 抖音页面偶发风控时，等十几秒会自动重试

**画面右侧排行榜挡住画面**

排行榜是半透明面板；如果觉得挡，可以把 OBS 里的源整体缩放，或在 `public/game.js` 调整面板坐标。

**端口被占用**

改 `config.json` 的 `port`，重启后 OBS 地址跟着改。

**没有语音播报**

- 控制台看「语音播报」是不是被关掉了，按钮状态会写进 `config.json`
- OBS 浏览器源右键 → 属性，勾选「控制音频通过 OBS」，再检查混音器里这个源没静音
- 普通 Chrome 预览时点一下画面解锁自动播放；OBS 浏览器源一般不用点
- 服务端控制台出现「语音合成失败」时，检查系统是否装了中文语音（设置 → 时间和语言 → 语音）

**改了游戏代码画面没变**

OBS 浏览器源右键「刷新页面」；或控制台重新点「打开直播画面」。
